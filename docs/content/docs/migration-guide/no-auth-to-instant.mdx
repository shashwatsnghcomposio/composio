---
title: Migrate from No Auth to Instant
description: Replace retiring shared-access tools before 13 November 2026
keywords: [No Auth, Instant, migration, Sessions, shared access]
---

Move affected shared-access workflows to [Instant Tools](/docs/instant-tools) or to provider credentials connected by your users before **13 November 2026**.

Follow the [Instant setup instructions](/docs/instant-tools#enable-instant), then replace the affected toolkit references below. Enabling Instant does not rewrite your application's tool names, arguments, or response handling.

## Replace affected toolkits

| Toolkit | Change | Migration path |
| --- | --- | --- |
| Gemini (`gemini`) | No Auth/shared-key access ends; the toolkit remains | Use supported Gemini Instant tools or credentials connected by your users. |
| Yelp (`yelp`) | No Auth/shared-key access ends; the toolkit remains | Use eligible Yelp Instant tools or supported credentials connected by your users. |
| Browser Tool (`browser_tool`) | Legacy toolkit retired | Replace with supported Browser Use (`browser_use`) Instant tools. |
| Composio Search (`composio_search`) | Legacy toolkit retired | Choose Exa (`exa`), Tavily (`tavily`), or SerpAPI (`serpapi`) tools for your use case. |
| Text to PDF (`text_to_pdf`) | Toolkit removed | PDF.co (`pdf_co`) Instant supports URL-based conversion. |
| WeatherMap (`weathermap`) | Toolkit removed | Use supported AccuWeather (`accu_weather`) Instant tools and update requests and response handling. |
| SeatGeek (`seat_geek`) | No Auth/shared-key access ends | SeatGeek will be available through Composio Instant. |


[Check the replacement action's Instant support, rate, and schema](/docs/instant-tools#find-supported-tools-and-rates) before updating a workflow. Toolkit-level support does not guarantee that every action is eligible.

## Update your application

### Agents using Sessions

Keep your existing agent integration. Replace retired toolkit references in the Session's filters, for example `composio_search` with `exa`, and update any tool allowlists to the replacement action names. Update saved Session configurations too. Update or recreate existing Sessions that still reference retired toolkits.

If your Session already permits Instant, you don't need additional Instant configuration. For restrictions and code examples, see [Instant controls](/docs/instant-tools#control-instant-usage) and [passing tools to your agent](/docs/instant-tools#pass-instant-tools-to-your-agent). You can also use the [optional Session setup helper](/docs/instant-tools#create-a-session-with-the-optional-helper).

### Direct-tool callers

Replace affected tool references and follow [using Instant with direct-tool calls](/docs/instant-tools#use-instant-with-direct-tool-calls). Keep your direct-tool version configuration up to date. An older pinned version will not preserve retired shared access.

You can also [migrate direct-tool execution to Sessions](/docs/migration-guide/direct-to-sessions). Agents already using Sessions don't need that separate migration.

## Test before the cutoff

Test each affected workflow with its replacement actions before 13 November. Check arguments, response parsing, tool allowlists, saved configurations, and existing Sessions. Use the [Instant troubleshooting and execution-log guidance](/docs/instant-tools#balance-usage-and-troubleshooting) to check which account ran a call and investigate failures.

After the cutoff, affected legacy executions will stop working. Contact [support@composio.dev](mailto:support@composio.dev) if you need help mapping a tool or updating a workflow.
